## 🚀 Signature Work

### 👑 Future Admiral Premium Spot — Institutional Autonomous Trading System

The current flagship system. A production-grade autonomous spot trading engine combining **Range Filter B&S confirmation**, **multi-agent AI debate**, and **capital-preservation-first risk framework**. Deployed on GitHub Actions with 8 scans per day at zero infrastructure cost.

**Core Architecture**
- **Range Filter B&S** — Pine Script port confirming every entry (LONG/SHORT veto)
- **Multi-Agent AI Committee** — Bull vs Bear vs Chief Risk Officer debate via Groq `openai/gpt-oss-120b`
- **5 Momentum Setups** — BREAKOUT · MOMENTUM · TREND · PULLBACK · SUPPORT_BOUNCE
- **Deep Technical Analysis** — RSI · EMA20/50/100 · 20d/50d ranges · volatility · volume surge · multi-timeframe changes
- **Top 100 Asset Universe** — Institutional-grade screening via Binance/Kraken/Bybit with automatic failover
- **Paper Trading Engine** — Auto-tracks every signal (WIN/LOSS/EXPIRED) in Supabase
- **Portfolio Manager** — Max 5 concurrent positions · 2% risk per trade · drawdown halt
- **Silent Mode** — Zero Discord spam on weak signals (volume < 0.8x)
- **Discord Reports** — Professional embeds with entry/target/stop/80-20 profit split
- **TradingView CSV Export** — Direct chart plotting for manual verification

**Stack:** `Python` · `GitHub Actions` · `Groq LPU` · `Supabase` · `Discord Webhooks` · `Binance API` · `Kraken API` · `Bybit API` · `Pandas` · `CCXT`
